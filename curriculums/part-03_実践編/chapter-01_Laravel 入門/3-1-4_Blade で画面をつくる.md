# Blade で画面をつくる

画面のファイルを用意して、プログラムから渡した値を表示します。

## Blade とは

Blade は、Laravel の画面ファイルです。

前のセクションでは、ルートに書いた文字がそのまま画面に出ました。ただ、本物の画面には見出しや色や並びが必要です。それを全部ルートに書くと、すぐに読めなくなります。

そこで画面は別のファイルに分け、`resources/views` に置きます。中身は入門編で書いた HTML とほぼ同じで、そこに `{{ }}` という書き方を混ぜられるのが Blade の特徴です。この `{{ }}` の中に変数を入れると、その中身が画面に出ます。

ファイル名は `chat.blade.php` のように、`.blade.php` で終わらせます。

## 変数の渡しかた

ルートから画面へ値を渡すときは、名前をつけて渡します。

```php
return view('chat', ['name' => 'ゆい']);
```

`view` は、4つの役割を見たときの「ビュー」です。ビューにあたるのが Blade で、この1行はその画面を呼び出しています。`'chat'` が画面ファイルの名前（`chat.blade.php` の前半）、`['name' => 'ゆい']` が渡す値です。名前つきリストの形なので、入門編で書いた配列と同じです。

受け取る側は、その名前を `{{ }}` で囲みます。

```blade
<p>{{ $name }}</p>
```

これで `<p>ゆい</p>` として表示されます。渡すときの名前に `$` を付けたものが、画面側の変数の名前です。`'name'` で渡したので、画面側は `$name` になります。入門編のように自分で `$name = 'ゆい';` と書く行はありません。ルートから渡した値が、すでにその名前で入っています。

## 実践: 名前を画面に出す

ここからは、ファイル一覧と編集エリアとブラウザだけで進みます。ターミナルの `php artisan serve` は、止めずに置いておいてください。

### Step 1: 画面のファイルができる

左のファイル一覧で `chat-app` の中の `resources` を開き、さらに `views` を開いてください。中に、はじめに見たようこそ画面のファイル `welcome.blade.php` があります。

その `views` を右クリックして「新しいファイル...」を選び、`chat.blade.php` と打って Enter を押してください。名前は半角で、`.blade.php` まで続けて打ちます。

中央の編集エリアに空のファイルが開きます。次の内容を入れてください。

```blade title="resources/views/chat.blade.php"
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>チャット</title>
</head>
<body>
  <h1>チャット</h1>
  <p>{{ $name }}さん、こんにちは</p>
</body>
</html>
```

### Step 2: `/chat` に名前が表示される

この画面を出すルートを足します。`routes/web.php` を開き、いちばん下の `});` の行のすぐ下に、次の3行を足してください。ここは足すだけです。ファイル全体を選んで貼り替えると、前のセクションで書いた `/` と `/hello` が消えます。

```php title="routes/web.php"
Route::get('/chat', function () {
    return view('chat', ['name' => 'ゆい']);
});
```

自分のファイルと見比べたいときは、次を開いてください。

??? note "足したあとの routes/web.php の全体"

    `});` の行が3つ並んでいれば足せています。空の行はなくてもかまいません。

    ```php title="routes/web.php"
    <?php

    use Illuminate\Support\Facades\Route;

    Route::get('/', function () {
        return view('welcome');
    });

    Route::get('/hello', function () {
        return 'はじめまして';
    });

    Route::get('/chat', function () {
        return view('chat', ['name' => 'ゆい']);
    });
    ```

ブラウザに戻り、アドレスの右のはしを2回押してください。1回目は全体に色が付き、2回目でその位置から直せる状態になります。末尾の `/hello` が消えるまで、`Backspace` キーを押してください（Mac では `delete` キーです）。続けて `/chat` と打ち、Enter を押します。

色が付いたまま打つと、検索の結果に飛びます。そのときはブラウザの戻るボタンでこの画面にもどり、右のはしを押すところからやり直してください。

画面に「ゆいさん、こんにちは」と表示されます。

![白い画面に「チャット」という太字の見出しがあり、その下に「ゆいさん、こんにちは」と表示されたページ](../../../assets/diagrams/output/3-1-4-cap01-chat-name.png)

画面に `{{ $name }}` がそのまま文字として出て、名前が入らないときは、ファイルの名前を見てください。`.blade` が抜けて `chat.php` になっていると、`{{ }}` は印として働かず、書いたものがそのまま出ます。エラーは出ないので、手がかりは名前だけです。直すときは右クリックして「名前の変更...」を選びます。

!!! failure "よくあるエラー"

    渡した名前と画面側の名前が食い違うと、前のセクションで読み方をおぼえたエラーの画面になります。画面のいちばん上には、次の4行が並びます。

    ```text
    Internal Server Error
    ErrorException
    resources/views/chat.blade.php:9
    Undefined variable $name
    ```

    **原因**: 入門編では、変数の名前を打ち間違えても、その場所だけ空のまま表示が続きました。Blade では、そこで止まります。エラーになった行より前に書いた `<h1>チャット</h1>` の見出しさえ出ず、画面はまるごとこのエラーに変わります。

    **対処法**: ルート側の `'name'` と、画面側の `{{ $name }}` のつづりを見比べて、そろえてください。同じ症状は、困ったときに戻るページにも載せてあります。

### Step 3: 変えた名前が画面に出る

`'ゆい'` の部分を自分の名前に変えて、開き直してみてください。画面の文字が変わります。プログラムで決めた値が画面に出る、という流れがここで一度つながりました。

!!! note "補足"

    `{{ }}` は、渡された文字をそのまま安全に表示します。もし文字の中に画面を壊すような記号が混ざっていても、記号のまま表示してくれます。他人が書いた文字を表示するチャットでは、この安全さが効いてきます。

**確認**: `/chat` を開くと、ルートで指定した名前が画面に表示されます。

## まとめ

- 画面は `resources/views` に `.blade.php` のファイルとして置く
- ルートから `view('ファイル名', ['名前' => 値])` で値を渡せる
- 画面側は `{{ $名前 }}` で受け取って表示する
- 渡した名前と画面側の名前が食い違うと、画面いっぱいのエラーになる

次のセクションでは、この画面をチャットらしい見た目に組み上げます。仮の会話を名前つきリストで用意し、くり返しで吹き出しとして並べて、アプリの器を完成させます。

# サンプルの会話を入れる

空の表に、サンプルの会話を入れて中身のある状態にします。

## モデルとは

`messages` の表はできましたが、中身は空のままです。表はデータベースの中にあり、PHP のコードから直接さわれるものではないので、会話を入れるにはあいだに立つ相手が必要です。

その相手になるのがモデルです。レストランのたとえでは、食材置き場から食材を出し入れする食材係として出てきた役割です。データベースへの出し入れは、すべてモデルを通します。

モデルは表ごとに1つ用意します。`messages` の表を受け持つのは、1件ぶんを指す `Message` という名前のモデルです。この対応があるので、`Message` に頼めば Laravel が `messages` の表を見つけます。

## シーダーとは

モデルを用意しても、入れる会話そのものはまだどこにもありません。1件ずつ手で打ち込む場所もないので、入れたい中身をファイルに書いておき、コマンドでまとめて入れます。

このファイルがシーダーで、最初のデータを入れるための道具です。モデルと同じく、コマンドで出してもらえます。

## 実践: 最初の会話を入れる

前のセクションでコマンドを打ったターミナルを、そのまま使います。作業部屋を開き直してターミナルが空のときは、新しく開いて `cd chat-app` を済ませてください。ブラウザは使わないので、`php artisan serve` は動いていなくてもかまいません。

入れる相手の表が要るので、前のセクションの `php artisan migrate` が済んでいることを確かめてください。済んでいれば、打ち直す必要はありません。

### Step 1: Message モデルができる

同じターミナルで、次のコマンドを打ちます。

```bash
php artisan make:model Message
```

```text
   INFO  Model [app/Models/Message.php] created successfully.
```

左のファイル一覧で `chat-app` の中の `app` を開き、さらに `Models` を開いてください。いま増えた `Message.php` があります。押して開くと、次の内容が入っています。

```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Message extends Model
{
    //
}
```

中身はほとんど空ですが、これで `messages` の表を扱う係ができました。`//` は、ここには何も書かれていないという印です。このセクションでは、このファイルには何も書き足しません。

同じフォルダに `User.php` が並んでいます。Laravel が最初から用意しているもので、この教材では使わないので、開かなくてかまいません。

### Step 2: 入れるデータを書く

シーダーのファイルを出してもらいます。同じターミナルで打ちます。

```bash
php artisan make:seeder MessageSeeder
```

```text
   INFO  Seeder [database/seeders/MessageSeeder.php] created successfully.
```

`database` の中の `seeders` を開くと、`MessageSeeder.php` があります。開いて、ファイル全体を次の内容にまるごと置き換えてください。

```php title="database/seeders/MessageSeeder.php"
<?php

namespace Database\Seeders;

use App\Models\Message;
use Illuminate\Database\Seeder;

class MessageSeeder extends Seeder
{
    /**
     * Run the database seeds.
     */
    public function run(): void
    {
        Message::create(['name' => 'はな', 'body' => 'こんにちは！このチャット、自分で作ったんだって？']);
        Message::create(['name' => 'そら', 'body' => 'そう。Laravel っていう道具で作ったよ']);
        Message::create(['name' => 'はな', 'body' => 'すごい、ほんとに動いてる']);
        Message::create(['name' => 'そら', 'body' => 'メッセージはデータベースに残るから、消えないよ']);
        Message::create(['name' => 'はな', 'body' => 'じゃあ記念にひとこと。はじめまして！']);
    }
}
```

`Message::create` は、名前つきリストの中身で表に1行つくります。`'name'` に名前、`'body'` に本文が入り、この5行で5件ぶんです。会話の中身は自分の言葉に変えてもかまいませんが、`'name'` と `'body'` の名前はそのままにしてください。

### Step 3: 会話がデータベースに入る

シーダーは、`DatabaseSeeder` というファイルから呼ばれて動きます。`MessageSeeder` を呼ぶように、こちらも書き替えます。

同じ `seeders` の中にある `DatabaseSeeder.php` を開いてください。もともと書かれているのは、Laravel が用意した練習用のデータを入れる行です。この教材では使わないので、ファイル全体を次の内容にまるごと置き換えます。

```php title="database/seeders/DatabaseSeeder.php"
<?php

namespace Database\Seeders;

use Illuminate\Database\Seeder;

class DatabaseSeeder extends Seeder
{
    /**
     * Seed the application's database.
     */
    public function run(): void
    {
        $this->call([
            MessageSeeder::class,
        ]);
    }
}
```

これで準備がそろいました。同じターミナルで、最後のコマンドを打ちます。

```bash
php artisan db:seed
```

出力例です（かかった時間は環境によって変わります）。

```text
   INFO  Seeding database.

  Database\Seeders\MessageSeeder ..................................... RUNNING
  Database\Seeders\MessageSeeder .................................. 15 ms DONE
```

`MessageSeeder` の行が2つ出ます。上が動き出したところ、下が終わったところです。末尾の `DONE` は、書いた5件が最後まで通ったという合図です。途中で1件でも失敗していれば、そこで止まって英語のエラーが出ます。

!!! failure "よくあるエラー"

    表をつくらないまま `php artisan db:seed` を打つと、ターミナルに長いエラーが出ます。その中に、次の文字ではじまる行があります。

    ```text
    SQLSTATE[HY000]: General error: 1 no such table: messages
    ```

    **原因**: 会話を入れる相手の `messages` の表が、まだできていません。

    **対処法**: `php artisan migrate` を先に打ち、もう一度 `php artisan db:seed` を打ってください。

    同じ症状は、困ったときに戻るページにも載せてあります。

何件入ったかは、ターミナルには出ません。次のセクションで画面をデータベースにつなぐと、いま書いた5件がそのまま吹き出しになって並びます。数がそろっているかは、そこで見て確かめられます。

!!! warning "注意"

    `php artisan db:seed` をもう一度打つと、同じ会話がもう一組増えます。二重に並んでしまったときは、`php artisan migrate:fresh` で表をつくり直してから `php artisan db:seed` を打つと、5件に戻ります。

**確認**: `php artisan db:seed` と打つと、`MessageSeeder` の行に `DONE` と出ます。

## まとめ

- モデルは表を扱う係で、`messages` の表には `Message` という名前のモデルを用意する
- シーダーは最初のデータを入れるための道具で、入れる会話を `MessageSeeder` に書いておく
- `php artisan db:seed` を打つと、書いておいた会話がデータベースの表に入る

次のセクションでは、仮の会話を差し替えて、データベースから取り出した会話を画面に並べます。ルートで `Message::all()` を使って表の中身を取り出し、Blade へ渡します。

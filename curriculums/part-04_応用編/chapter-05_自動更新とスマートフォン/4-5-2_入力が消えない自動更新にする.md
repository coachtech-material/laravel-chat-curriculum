# 入力が消えない自動更新にする

打ちかけの文字を消さずに、新しいメッセージだけが届くようにします。

## 画面の一部だけ入れ替える

前のセクションで文字が消えたのは、ページ1枚をまるごと読み直していたからです。会話だけでなく入力欄とヘッダーまで、まとめて作り直されました。打ちかけの文字を守るには、新しくする範囲を会話の部分だけに狭めます。

狭めるには、場所に名前が要ります。HTML には、かたまりに名前を付けておく `id` という書き方があります。見た目をまとめて付けるときに使ってきた `class` は、同じ名前がいくつの場所にあってもかまいません。`id` のほうは、画面の中の1か所だけを名指しするための目印です。メッセージの表にある `id` の列と同じつづりですが、そちらとは別のものです。

会話のかたまりに `messages` という名前を付けておくと、あとから3つの手順でその場所だけを新しくできます。いま開いているのと同じ住所をもう一度サーバーから取りに行き、返ってきたページの中から同じ名前の場所を探して、いま出ている画面のその場所と中身を入れ替えます。

入力欄は入れ替える範囲に入っていないので、打ちかけの文字はそのまま残ります。

## JavaScript とは

この3つの手順を進めるのは、PHP ではありません。PHP はサーバーの中で動いて、送り出す HTML を組み立てる言語でした。いま画面に出ているものをあとから書き替えるには、ブラウザの中で動く言語が要ります。それが JavaScript です。

書く場所は `<script>` です。チャット画面をつくったとき、見た目を付けるために `<head>` へ `<script>` で始まる1行を入れました。あのときの `<script>` と同じ入れ物で、今回はその中に数行の指示を書きます。

入れ物は同じですが、置く場所は違います。前は `<head>` の中で、今回はファイルのいちばん下にある `</body>` の直前です。`<script>` はどちらでも動くので、前と違っていても間違いではありません。

貼るのは8行のかたまり1つで、中身は読めなくてかまいません。さきほどの3つの手順を5秒ごとにくり返す、という指示が書いてあります。この教材で必ず書いてもらう JavaScript は、この数行だけです。

## 実践: 数行のしくみに差し替える

前のセクションから続けて進めます。ターミナルで `php artisan serve` が動いたまま、チャット画面を開いた状態から始めてください。作業部屋を開き直したときは、`cd chat-app` と `php artisan serve` をもう一度打ちます。

手を入れるのは全部で3か所です。どれも `resources/views/chat.blade.php` の中で、ほかのファイルは触りません。

1つめは、前のセクションで足した1行を消すことです。このファイルを開き、`<meta http-equiv="refresh" content="5">` の行を、行ごと消してください。ページ1枚をまるごと読み直す指示は、これでなくなります。自動更新はいったん止まりますが、3つめで入れ直します。

2つめは、会話のかたまりに名前を付けることです。かたまりの上と下に1行ずつ足すので、2回に分けて貼り替えます。

かたまりの上側です。`<main class="flex-1 overflow-y-auto p-4">` の行の先頭から `@foreach ($messages as $message)` の行の末尾まで（2行）を選び、次の3行に貼り替えてください。

```blade title="resources/views/chat.blade.php"
    <main class="flex-1 overflow-y-auto p-4">
      <div id="messages">
      @foreach ($messages as $message)
```

増えたのは真ん中の1行だけです。ここに書いた `messages` が、あとで場所を指すときの名前になります。

続いて、かたまりの下側です。`@endforeach` の行の先頭から `</main>` の行の末尾まで（2行）を選び、次の3行に貼り替えてください。

```blade title="resources/views/chat.blade.php"
      @endforeach
      </div>
    </main>
```

これで、吹き出しをくり返している部分が `<div id="messages">` と `</div>` にはさまれました。

3つめは、数行のかたまりを足すことです。ここは手で打たずに、コードの右上のボタンでコピーして貼り付けてください。見なれない記号が続くので、手で打つとつづりを取り違えやすい場所です。ファイルのいちばん下にある `</body>` の行の先頭から `</html>` の行の末尾まで（2行）を選び、次の10行に貼り替えてください。

```blade title="resources/views/chat.blade.php"
  <script>
    setInterval(async () => {
      const res = await fetch(location.href);
      const html = await res.text();
      const doc = new DOMParser().parseFromString(html, 'text/html');
      document.querySelector('#messages').innerHTML = doc.querySelector('#messages').innerHTML;
    }, 5000);
  </script>
</body>
</html>
```

うしろの2行はいままでどおりで、増えたのは `<script>` から `</script>` までの8行です。`</script>` のすぐ上にある `5000` が、さきほどと同じ5秒です。ここはミリ秒（1000分の1秒）で書く決まりなので、5秒は 5000 になります。

保存したら、チャット画面を開き直してください。入力欄に `まだ送っていません` と打ち、「送信」は押さずに5秒ほど待ちます。前のセクションでは消えた文字が、今度は残ったままです。

新しいメッセージが届くかどうかは、ブラウザのタブを2つ使うと確かめられます。いま開いているチャット画面のアドレス欄を1回押すと、住所の全体に色が付きます。`Ctrl` キーと `C` キーを同時に押してコピーしてください（Mac では `command` キーと `C` キーです）。ブラウザのタブの並びのいちばん右にある `+` を押すと新しいタブが開くので、`Ctrl` キーと `V` キーを同時に押して貼り付け、Enter キーを押します。

同じチャット画面が2つのタブに並びます。

あとから開いたほうで `2つめのタブから送りました` と打って「送信」を押し、先に開いていたタブに切り替えてください。そのまま5秒ほど待ってから、会話を下までスクロールします。いちばん下に、いま送ったメッセージが増えています。新しいメッセージはいま見えているところより下に足されるので、届いてから下まで動かします。

2つのタブは同じブラウザなので、入室している名前も同じです。どちらから送っても、自分のメッセージとして緑の吹き出しで右に出ます。別の人から届くところは、次のセクションで確かめます。

!!! warning "注意"

    貼った数行のつづりを1文字でも取り違えると、入れ替える場所が見つかりません。エラーの言葉はどこにも出ません。気づくための手がかりは、もう片方のタブで送っても一覧が増えないことです。見比べるところは2つで、貼った数行の中に2回出てくる `#messages` と、会話のかたまりを囲んだ `<div id="messages">` です。この2つの名前をそろえてください。

なお、画面を長いあいだ開きっぱなしにしていると、正しく書けていても新着が止まります。入室した名前を預けてあるサーバーのメモには期限があり、時間がたつと消えるためです。メモが消えると、取りに行った先が会話ではなく入室画面に変わります。そのときは画面を開き直してください。入室画面が出るので、名前を入れて「入室する」を押し、ルームをもう一度開けば、また届くようになります。

**確認**: 入力欄に文字を打って5秒待っても消えず、もう片方のタブから送ったメッセージが、5秒ほどで会話のいちばん下に増えます。

## まとめ

- ブラウザの中で動く JavaScript を使うと、いま出ている画面の一部を、あとから書き替えられる
- 入れ替える場所は `id` で名前を付けて指す。ページ1枚を読み直さないので、打ちかけの文字は消えない
- くり返しているのは5秒おきの取り直しで、送った瞬間に届く本物のメッセージアプリのしくみは、もっと先の技術になる

次のセクションでは、いま自分だけが見ているチャットを外から開けるように公開して、自分のスマートフォンから開きます。スマートフォンで送ったメッセージがパソコンの画面に自動で出るところまで確かめたら、最後に公開をやめます。

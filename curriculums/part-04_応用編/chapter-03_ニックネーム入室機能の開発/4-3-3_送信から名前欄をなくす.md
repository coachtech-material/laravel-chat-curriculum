# 送信から名前欄をなくす

送信欄から名前の欄を消して、入室したときの名前で残るようにします。

## 名前の出どころを変える

消すのは画面ファイルの2か所で、名前の入力欄と、名前が空のときに赤い文字を出すかたまりです。受け取る係は、入力チェックから名前を外し、保存する名前を預けてあるものに替えます。

## 未入室の人を案内する

名前を決めていない人が、いきなりルーム一覧の住所を開くこともあります。いまはそのまま開けて、右上の名前の場所だけが空になります。そのまま送られると、名前の無い1件を保存しようとして、画面いっぱいに英語のエラー画面が出ます。

そこで、係が仕事を始める前に `session('nickname')` の中身を確かめ、名前が無ければ入室画面へ送り返します。何も預けていないときに返るのは `null` で、中身が無いことを表します。これと同じなら `return redirect('/enter');` で送り返す、という3行です。

確かめるのは、ルーム一覧とチャット画面と、メッセージを送るときの3か所です。前の2つで案内するので、ふつうは送信までたどり着きません。それでも送るところにも置くのは、名前の無い1件が保存されようとするのを、その手前で止めるためです。

`return` は、そこで係の仕事を終わらせる印です。落とすと送り返しが起きず、その下の処理が続きます。

## 実践: 名前欄をなくす

前のセクションから続けて、`php artisan serve` が動いている状態で進めます。作業部屋を開き直したときは、`cd chat-app` を済ませたターミナルで `php artisan serve` を打ち直してください。画面の右上に自分の名前が出ている状態から始めます。出ていないときは、アドレスの末尾を `/enter` に変えて入室し直してください。打つコマンドはなく、書き替えるファイルは3つです。

### Step 1: 送信欄から名前の入力が消える

`resources/views/chat.blade.php` の `<footer` で始まる行の先頭から `</footer>` の行の末尾まで（16行）を選び、次の11行に貼り替えてください。

```blade title="resources/views/chat.blade.php"
    <footer class="bg-white p-3">
      <form action="/rooms/{{ $room->id }}" method="POST" class="flex gap-2">
        @csrf
        <input type="text" name="body" placeholder="メッセージを入力" value="{{ old('body') }}"
          class="flex-1 bg-gray-100 rounded-full px-4 py-2">
        <button type="submit" class="shrink-0 bg-green-500 text-white font-bold rounded-full px-5 py-2">送信</button>
      </form>
      @error('body')
        <p class="text-red-500 text-sm mt-2">{{ $message }}</p>
      @enderror
    </footer>
```

消えたのは5行で、名前の入力欄の2行と `@error('name')` の3行です。

チャット画面を開き直すと、下の帯の入力欄が1つになり、幅いっぱいに広がります。

![画面の下端に、幅いっぱいの「メッセージを入力」の欄と、その右の緑の「送信」ボタンだけが並んでいる](../../../assets/diagrams/output/4-3-3-cap01-single-input.png)

!!! warning "注意"

    ここではまだ「送信」を押さないでください。受け取る係が名前を求めたままなので保存の手前で止まり、赤い文字を出す場所も消したので、何も起きていないように見えます。

    押してしまい「名前を入力してください」と赤い文字が出たときは、`@error('name')` の3行が残っているので消してください。

### Step 2: 送ると自分のニックネームで残る

`app/Http/Controllers/ChatController.php` を開き、ファイル全体を次の内容にまるごと置き換えてください。消えるのが2行、書き替わるのが1行です。

```php title="app/Http/Controllers/ChatController.php"
<?php

namespace App\Http\Controllers;

use App\Models\Message;
use App\Models\Room;
use Illuminate\Http\Request;

class ChatController extends Controller
{
    public function store(Request $request, Room $room)
    {
        $validated = $request->validate([
            'body' => 'required',
        ], [
            'body.required' => 'メッセージを入力してください',
        ]);

        Message::create([
            'name' => session('nickname'),
            'body' => $validated['body'],
            'room_id' => $room->id,
        ]);

        return redirect('/rooms/' . $room->id);
    }

    public function edit(Message $message)
    {
        return view('edit', ['message' => $message]);
    }

    public function update(Request $request, Message $message)
    {
        $validated = $request->validate([
            'body' => 'required',
        ], [
            'body.required' => 'メッセージを入力してください',
        ]);

        $message->update($validated);

        return redirect('/rooms/' . $message->room_id);
    }

    public function destroy(Message $message)
    {
        $message->delete();

        return redirect('/rooms/' . $message->room_id);
    }
}
```

入力チェックに残ったのはメッセージの1つだけで、`update` と同じ形です。保存する名前は `session('nickname')` から来ます。

チャット画面を開き直し、入力欄に `名前を打たずに送れました` と入れて「送信」を押してください。いちばん下に `ゆい` の名前で吹き出しが増えます。

こんどは空のまま押してみましょう。同じルームにもどり、入力欄の下に赤い文字が1行だけ出ます。

```text
メッセージを入力してください
```

前は2行でした。足りないものがメッセージだけになったためです。

### Step 3: 名前を決めていない人を入室画面へ送る

足す3行は、3か所とも同じです。ここは足すだけで、ファイル全体は貼り替えません。

1つめは、ルーム一覧を出す係です。`app/Http/Controllers/RoomController.php` を開き、`public function index` で始まる行を探してください。その次の行は `{` だけの行です。そのすぐ下に、次の3行と、そのあとに空の行を1つ足します。`$rooms = Room::all();` の行は、下にずれます。

```php title="app/Http/Controllers/RoomController.php"
        if (session('nickname') === null) {
            return redirect('/enter');
        }
```

足したあとは、この形になります。行の先頭の空白の数も、この形と見比べられます。

```php title="app/Http/Controllers/RoomController.php"
    public function index()
    {
        if (session('nickname') === null) {
            return redirect('/enter');
        }

        $rooms = Room::all();

        return view('rooms', ['rooms' => $rooms]);
    }
```

2つめは、同じファイルのチャット画面を出す係です。少し下にある `public function show` で始まる行の、その次の `{` の行のすぐ下に、同じ3行と空の行を足します。

```php title="app/Http/Controllers/RoomController.php"
        if (session('nickname') === null) {
            return redirect('/enter');
        }
```

足したあとは、この形になります。

```php title="app/Http/Controllers/RoomController.php"
    public function show(Room $room)
    {
        if (session('nickname') === null) {
            return redirect('/enter');
        }

        $messages = $room->messages;

        return view('chat', ['room' => $room, 'messages' => $messages]);
    }
```

3つめは、さきほど書き替えた `ChatController.php` の、メッセージを受け取る係です。このファイルには `$validated = $request->validate([` で始まる行が2つありますが、足すのは上のほうです。`public function store` で始まる行の、その次の `{` の行のすぐ下に、同じ3行と空の行を足します。

```php title="app/Http/Controllers/ChatController.php"
        if (session('nickname') === null) {
            return redirect('/enter');
        }
```

足したあとは、`store` の始まりがこの形になります。

```php title="app/Http/Controllers/ChatController.php"
    public function store(Request $request, Room $room)
    {
        if (session('nickname') === null) {
            return redirect('/enter');
        }

        $validated = $request->validate([
            'body' => 'required',
        ], [
            'body.required' => 'メッセージを入力してください',
        ]);
```

この3行が効くのは名前を決めていない人が開いたときだけなので、入室したまま使うあいだは見え方が変わりません。ルーム一覧を開き直してルームを1つ押すと、これまでどおり会話が並び、もう1件送れます。書けているかどうかは、上に出した3つの形と見比べれば分かります。あとの章で自分のスマートフォンから開くときは、名前を決めていない状態から始まるので、この案内が働くところを見られます。

!!! failure "よくあるエラー"

    名前を決めていない人がルーム一覧やチャット画面を開けてしまう。または「送信」で画面いっぱいに英語のエラー画面が出る。

    ```text
    QueryException
    SQLSTATE[23000]: Integrity constraint violation: 19 NOT NULL constraint failed: messages.name
    ```

    **原因**: `return` を書き忘れて `redirect('/enter');` とだけ書いています。書き忘れても、PHP は注意を出しません。

    **対処法**: 英語のエラー画面が出たときは、先に戻るボタンを押してもどってください。一覧やチャット画面が開けてしまうときは `RoomController` の2か所、英語のエラー画面が出るときは `ChatController` です。`redirect` の前に `return` を足します。

最後に、今日の分を記録して終わりましょう。左端のアイコンの列から「ソース管理」を押し、メッセージを打って「コミット」、続けて「変更の同期」を押します。手順の詳しい説明は、はじめて保存の儀式をしたページにあります。

```text
ニックネームで入室できるようにした
```

## 完成チェックリスト

- 名前を入れて「入室する」を押すと、ルーム一覧が出て、右上に自分の名前が出ている
- 送信欄の入力欄が1つだけになっている
- メッセージだけ打って「送信」を押すと、入室した名前で吹き出しが増える
- 空のまま「送信」を押すと、赤い文字が1行だけ出る
- 入室画面へ送り返す同じ3行が、3か所の係に入っている
- 今日の分が GitHub に上がっている

## まとめ

- 送信欄から名前の欄を消し、保存する名前はセッションから取り出すようにした
- 名前が預けられていないときは、係が仕事を始める前に入室画面へ送り返す。`return` を落とすと働かない
- 同じ3行を3か所に書いた。1度書けば全部に効かせるやり方もあるが、この教材では扱わない

この章では、ニックネームを決めて入る画面をつくり、決めた名前をサーバーにおぼえてもらいました。

次の章では、自分の発言と相手の発言を、見た目で見分けられるようにします。入室した名前と、メッセージに残っている名前を比べて、自分が送ったものだけ右に寄せます。そのあとは、吹き出しに送った時刻を添えます。

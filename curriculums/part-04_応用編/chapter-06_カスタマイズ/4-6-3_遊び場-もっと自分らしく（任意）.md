# 遊び場: もっと自分らしく（任意）

ここからは自由課題です。手順のかわりに目標だけを見て、自分で書いてみます。

## 挑戦する前の確認

ここまでのセクションには、書き替える行と、そこへ貼るコードが必ず載っていました。このセクションに載っているのは、4つのアイデアと、それぞれの目標と、書き替えるファイルの名前だけです。

選ぶのは1つで足ります。4つそろえる必要はありません。

答えは、このページの下のほうに置いてあります。手が止まったときは、いつ開いてもかまいません。先に読んでから写す進め方でも問題ありません。

このセクションをやらなくても、チャットは完成します。次の章の仕上げは、ここで何をしたかにかかわらず、同じ手順で進みます。

## アイデア集

4つのアイデアは、上からやさしい順に並べています。下へ行くほど、この教材でまだ説明していない書き方が増えます。いちばん下の絵文字のボタンは、ここまでに出てきた書き方だけでは届きません。途中で手が止まっても、そこまでで大丈夫です。

### 背景の色を変える

会話のうしろに広がっている灰色を、自分の好きな色にします。書き替えるのは `resources/views/chat.blade.php` の中の1か所です。

**目標**: チャット画面を開くと、会話のうしろが自分で選んだ色になっていて、白い吹き出しの文字もそのまま読めます。

濃さの番号は色をまとめて変えたときに `500` のままにしましたが、ここは変えてかまいません。`100` から `900` まで 100 きざみで、小さいほど淡くなります。面いっぱいに広がるので、淡いほうが名前や時刻の小さな文字も読みやすく保てます。`150` や `1000` のような無い番号を書いても、色は変わりません。

これができて物足りないときは、吹き出しの色との組み合わせまで自分で決めてみてください。

### メッセージの件数を出す

ルームを開いたときに、そのルームのメッセージが何件あるかを、ヘッダーの名前のとなりに出します。書き替えるのは、こちらも `resources/views/chat.blade.php` です。

**目標**: ルームを開くと、名前のとなりに数字が出ます。メッセージを1つ送るとその数字が1つ増え、まだ何も送っていないルームを開くと 0 と出ます。

並んでいるものがいくつあるかを数える書き方が PHP にあります。この教材ではまだ使っていないので、名前は自分で探すことになります。

### 入室したときにあいさつする

ニックネームを入れて入室した人に、あいさつを1回だけ出します。触るのは `app/Http/Controllers/EnterController.php` と `resources/views/rooms.blade.php` の2つです。係と画面の両方を書き替えるのは、4つの中でこれだけです。

**目標**: 名前を入れて入室すると、そのあとに出るルーム一覧の画面に「ゆいさん、ようこそ」のように出ます。同じ画面を開き直すと、あいさつは消えています。

開き直すと消えるのは、一度出したらなくなる渡し方をするからです。チャット画面のほうに書くと、そこへたどり着く前にルーム一覧で使われてしまい、いつまでも出ません。

### 絵文字を入れるボタンを足す

入力欄のとなりに小さなボタンを置いて、押すと入力欄に絵文字が入るようにします。書き替えるファイルは `resources/views/chat.blade.php` です。

**目標**: ボタンを押すと入力欄に絵文字が入ります。押しただけでは送信されず、もう一度押すと絵文字が2つ並びます。そのまま「送信」を押すと、絵文字の入ったメッセージが会話に出ます。

画面の一部だけを入れ替えるしくみを入れたときに貼った JavaScript を、こんどは自分で書くことになります。

## 実践: 選んだアイデアをつくる

前のセクションから続けているなら、そのままの状態で始められます。作業部屋を開き直したときは、ターミナルで `cd chat-app` と `php artisan serve` を打ってから、チャット画面を開いてください。

書き替えたら保存して、ブラウザで画面を開き直します。

思ったとおりにならないときは、`Ctrl` キーと `Z` キーを同時に押すと、ひとつ前にもどります（Mac では `command` キーと `Z` キーです）。何度か押せば、書きはじめる前の状態まで戻せます。

英語のエラー画面が出たときは、戻るボタンでもどってください。画面に出た言葉から、困ったときに戻るページで直し方を引けます。

試しているあいだに、書きかけのメッセージが送られてしまうことがあります。そのときは、いつもどおり吹き出しの下の「削除」で消せます。

手が止まったら、下の答え合わせを開いてください。

## 答え合わせ

書けなかったところは、ここのコードをそのまま写してかまいません。

??? note "背景の色を変える"

    `resources/views/chat.blade.php` の上のほうに、`<div class="max-w-md` で始まる行があります。いま `bg-gray-200` と書いてあるところが、会話のうしろの色です。この行を選び、次の1行に貼り替えてください。

    ```blade title="resources/views/chat.blade.php"
      <div class="max-w-md mx-auto h-screen flex flex-col bg-sky-100 shadow-lg">
    ```

    `sky` はうすい水色です。`rose` にすればうすい桃色、`violet` にすればうすい紫になります。

??? note "メッセージの件数を出す"

    同じファイルのヘッダーの中に、ルームの名前を出している行があります。`<h1 class="font-bold">{{ $room->name }}</h1>` の行を選び、次の1行に貼り替えてください。

    ```blade title="resources/views/chat.blade.php"
          <h1 class="font-bold">{{ $room->name }}（{{ count($messages) }}）</h1>
    ```

    `count` は、いくつあるかを数える PHP の道具です。数える相手の `$messages` は、すぐ下のくり返しが使っている一覧そのものです。波かっこ2つの中に道具を書く形は、名前から1文字目を取り出したときと同じです。

    自動で新しくなるのは会話の部分だけなので、この数はページを開き直すまで増えません。ほかの人のメッセージが届いて吹き出しだけが増えても、壊れているのではなく、入れ替える範囲を会話に狭めたことが、そのまま出ています。

??? note "入室したときにあいさつする"

    書き替えるのは2つのファイルです。`app/Http/Controllers/EnterController.php` を開いてください。入室のあとルーム一覧へ送り返している `return redirect('/rooms');` の行を選び、次の1行に貼り替えてください。

    ```php title="app/Http/Controllers/EnterController.php"
            return redirect('/rooms')->with('greeting', $validated['nickname'] . 'さん、ようこそ');
    ```

    うしろに付けた `->with(...)` が、次に開く画面へ値を1回だけ持ち越します。持ち越す値には `greeting` という名前を付け、送られてきたニックネームに `さん、ようこそ` をつないだ文を入れています。

    続いて `resources/views/rooms.blade.php` です。`<main class="flex-1 overflow-y-auto p-4">` の行のすぐ下に、次の3行を足してください。`@foreach ($rooms as $room)` の行は、下にずれます。ここは足すだけで、ファイル全体は貼り替えません。

    ```blade title="resources/views/rooms.blade.php"
          @if (session('greeting'))
            <p class="text-center text-gray-600 mb-4">{{ session('greeting') }}</p>
          @endif
    ```

    受け取るのは `session('greeting')` です。ニックネームを取り出すのと同じ書き方ですが、こちらは1回出すとなくなります。ルーム一覧を開き直すとあいさつが消えているのは、そのためです。

??? note "絵文字を入れるボタンを足す"

    同じ `resources/views/chat.blade.php` の下のほうに、送信のフォームがあります。`<input type="text" name="body"` で始まる行を選び、次の3行に貼り替えてください。すぐ下の `class="flex-1` で始まる行は、そのままにします。

    ```blade title="resources/views/chat.blade.php"
            <button type="button" onclick="document.querySelector('#body').value += '😊'"
              class="shrink-0 bg-white rounded-full px-3">😊</button>
            <input type="text" id="body" name="body" placeholder="メッセージを入力" value="{{ old('body') }}"
    ```

    増えたのはボタンの2行と、入力欄に足した `id="body"` です。ボタンの `onclick` は、押したときに動く指示です。`document.querySelector('#body')` で入力欄を名指しし、`.value` でその中身を指して、`+=` でうしろに絵文字を1つ足しています。名指しに使う `#body` が、入力欄に足した `id="body"` と対です。会話のかたまりを `#messages` で名指ししたのと同じ形になっています。

    !!! warning "注意"

        ボタンに `type="button"` を書かないと、押した瞬間にメッセージが送られます。フォームの中のボタンは、何も書かないと送信ボタンとして動くためです。

        入力欄に `id="body"` を足し忘れると、押しても何も起きません。エラーの言葉はどこにも出ません。入力欄が空のまま変わらないことが、気づくための手がかりです。

## まとめ

- 目標だけを見て書くのは、書いてあるコードを写して動かすのとは別の作業になる。書けなかったところがあっても、いまは写して動かせれば十分
- 答え合わせのコードは、どれも1行から4行しかない。届かなかったのは、そういう書き方をまだ知らなかったからで、長さのせいではない

つくったものは、いつもの手順で記録しておきましょう。今日の分は前のセクションで済ませているので、メッセージは `遊び場で背景の色を変えた` のように、ここで足したぶんだけでかまいません。

次の章では、ここまでにつくったチャットを通しで動かして仕上げます。入室からメッセージの送信・編集・削除、自動で届くところまで順に確かめ、開いていちばん最初に出るページを自分のアプリの入口に変えて、完成を記録します。

# ルームの表をつくる

ルームを入れておく表を、メッセージの表と同じ手順で用意します。

## rooms の表のかたち

設計図に書き足す列は1つだけです。メッセージのときは名前と本文の2行を書きましたが、ルームが持つのは名前なので `name` の1行で足ります。`id` と時刻の2列は前と同じで、頼んだ時点で入っています。

できあがる表の列は、メッセージの表より1つ少ない4つです。

## 2つ目のシーダーで変わること

表ができたら、そこにルームを入れます。使うのは、サンプルの会話を入れたときと同じシーダーです。その2本目を書きます。

前と違うのは、入れるときに打つコマンドです。あのとき打った `php artisan db:seed` は、登録してあるシーダーを全部呼びます。2本目ができたあとにそのまま打つと、ルームと一緒にサンプルの会話までもう一度入り、同じ会話が二重に並びます。エラーの言葉はどこにも出ません。同じ会話が2つずつ並ぶことだけが、気づくための手がかりです。

そこで今回は、シーダーの名前を指定して、いま書いたぶんだけを入れます。

## 実践: ルームを3つ用意する

!!! success "確認"

    自分の GitHub のページから作業部屋を開いてください（「Code」→「Codespaces」）。今日は、ターミナルで `cd chat-app` を済ませ、`php artisan serve` が動いている状態から始めます。作業部屋を開き直した直後は、この2つを自分で打ってください。ブラウザは、右下に出る知らせの「ブラウザーで開く」から開きます。前のタブが残っていれば、そのタブを再読み込みしてもかまいません。`/chat` を開くと、これまでの会話が吹き出しで並び、それぞれの下に「編集」と「削除」が付いています。

`php artisan serve` を動かしているターミナルはふさがっています。ターミナルの右上にある `+` を押してもう1つ開き、そちらで `cd chat-app` を済ませてください。

### Step 1: rooms の表ができる

設計図のファイルを出してもらいます。

```bash
php artisan make:migration create_rooms_table
```

出力例です（ファイル名の前半の数字は、打った時点をもとに決まります）。

```text
   INFO  Migration [database/migrations/2026_07_29_081924_create_rooms_table.php] created successfully.
```

左のファイル一覧で `chat-app` の中の `database` を開き、さらに `migrations` を開いてください。いま増えたファイルが、いちばん下にあります。押して開いてください。

`$table->id();` の行のすぐ下に、次の1行を足してください。`$table->timestamps();` の行は、下にずれます。

```php
            $table->string('name');
```

足したあとは、この形になります。

```php
        Schema::create('rooms', function (Blueprint $table) {
            $table->id();
            $table->string('name');
            $table->timestamps();
        });
```

データベースに反映します。

```bash
php artisan migrate
```

出力例です（数字とかかった時間は環境によって変わります）。

```text
   INFO  Running migrations.

  2026_07_29_081924_create_rooms_table ........................... 2.99ms DONE
```

出るのは1行だけです。前につくった表の行は、もう反映が済んでいるので出てきません。末尾に `DONE` と付いていれば、`rooms` の表ができています。

### Step 2: Room モデルができる

表を扱う係も、前と同じコマンドで出してもらいます。

```bash
php artisan make:model Room
```

```text
   INFO  Model [app/Models/Room.php] created successfully.
```

`app` の中の `Models` を開くと、`Room.php` が増えています。押して開くと、次の内容が入っています。

```php title="app/Models/Room.php"
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Room extends Model
{
    //
}
```

今回、このファイルに書き足すものはありません。`rooms` の表を扱う係ができれば、それで足ります。

### Step 3: 3つのルームが入る

入れる中身を書くファイルを出してもらいます。

```bash
php artisan make:seeder RoomSeeder
```

```text
   INFO  Seeder [database/seeders/RoomSeeder.php] created successfully.
```

`database` の中の `seeders` を開くと、`RoomSeeder.php` があります。開いて、ファイル全体を次の内容にまるごと置き換えてください。

```php title="database/seeders/RoomSeeder.php"
<?php

namespace Database\Seeders;

use App\Models\Room;
use Illuminate\Database\Seeder;

class RoomSeeder extends Seeder
{
    /**
     * Run the database seeds.
     */
    public function run(): void
    {
        Room::create(['name' => 'おしゃべり']);
        Room::create(['name' => 'メモ']);
        Room::create(['name' => 'れんらく']);

        $this->command->info('ルームを3つ入れました');
    }
}
```

`Room::create` で `rooms` の表に1行つくります。この3行で、ルームが3つぶんです。最後の1行は、入れ終わったことをターミナルに出すためのものです。

書いたシーダーは、`DatabaseSeeder` にも登録しておきます。同じ `seeders` の中の `DatabaseSeeder.php` を開いてください。`$this->call([` の行のすぐ下に、次の1行を足します。`MessageSeeder::class,` の行は、下にずれます。ここは足すだけで、ファイル全体は貼り替えません。

```php title="database/seeders/DatabaseSeeder.php"
            RoomSeeder::class,
```

ルームを先に呼び、メッセージをあとから呼ぶ形になります。

```php title="database/seeders/DatabaseSeeder.php"
        $this->call([
            RoomSeeder::class,
            MessageSeeder::class,
        ]);
```

この1行は今日使いません。あとで表をつくり直すときのために書いておきます。そうすると、ルームも一緒に入ります。

ここまでそろったら、名前を指定して入れます。今日打つのはこちらだけで、シーダーを全部呼ぶ `php artisan db:seed` は打ちません。打つのは1回だけです。

```bash
php artisan db:seed --class=RoomSeeder
```

```text
   INFO  Seeding database.

ルームを3つ入れました
```

うしろの `--class=RoomSeeder` が、さきほど書いたシーダーの名前です。前に見た `RUNNING` と `DONE` の行は出ませんが、代わりに自分で書いた `ルームを3つ入れました` が出ます。この行が出れば、3つとも入っています。

!!! warning "注意"

    もう一度打つと、同じ名前のルームがもう一組増えます。同じ名前が2つ見えるだけで、この先の手順はそのまま進められるので、増えてもそのままにしておいてください。二重になったときの直し方として前に `php artisan migrate:fresh` を紹介しましたが、ここでは打たないでください。自分で送ったメッセージまで消えます。

ルームを並べる画面はこのあとつくります。3つの名前が画面に出るのは、そこからです。

いま確かめられるのは、入れる先の表です。

```bash
php artisan db:table rooms
```

```text
  main.rooms .................................................................
  Columns .................................................................. 4

  Column ................................................................ Type
  id integer, autoincrement .......................................... integer
  name varchar ....................................................... varchar
  created_at datetime, nullable ..................................... datetime
  updated_at datetime, nullable ..................................... datetime

  Index ......................................................................
  primary id ......................................................... primary
```

英語がたくさん出ますが、見るのは `Columns` の右の `4` と、その下に並ぶ列の名前だけです。自分で書いた `name` が、`id` と時刻の列のあいだに入っています。

**確認**: `php artisan db:table rooms` と打つと、`Columns` の右に `4` と出て、列の一覧に `name` が並びます。

## まとめ

- `rooms` の表は、設計図に `name` の1行を書き足してつくった。列は4つで、メッセージの表より1つ少ない
- 表を扱う係の `Room` はコマンドで出すだけでよく、書き足すものはなかった
- 2本目のシーダーは `--class=RoomSeeder` と名前を指定して、いま書いたぶんだけを入れる

次のセクションでは、メッセージの側に `room_id` という列を足して、どのルームのものかを覚えられるようにします。表はつくり直さなくても、あとから列を1つ増やせます。いままでの会話は、1つ目のルームのものになります。

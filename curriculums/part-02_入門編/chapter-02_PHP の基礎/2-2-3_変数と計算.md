# 変数と計算

名前や数を入れておく箱をつくって、組み合わせて表示します。

## 変数とは

前のセクションでは、出したい文字を `echo` のうしろに直接書きました。この書き方だと、同じ名前を何度も出す文章では、その名前を書いたところすべてに同じ文字が並びます。あとで名前を変えたくなったら、全部を探して打ち直すことになります。

一度決めた値に名前をつけて、置いておけるのが変数です。値に名前をつけて置いておく箱だと考えてください。あとはその名前で呼び出せば、入れておいたものが出てきます。

```php
$name = 'はな';
```

`$` を先頭に付けた `name` が、この値につけた名前です。名前は自分で決められます。`=` は「左に右を入れる」という印で、算数の等号とは意味が違います。右に書いた `'はな'` が、`$name` のところに入ります。

変数には数も入れられます。数は `'` ではさまずに、そのまま書きます。

```php
$members = 2;
```

入れた数は計算に使えます。使う記号は4つです。

| 書き方 | 意味 |
|---|---|
| `+` | 足す |
| `-` | 引く |
| `*` | かける |
| `/` | 割る |

足し算と引き算は算数と同じ記号です。かけ算は `*`、わり算は `/` で、算数の書き方とは違います。

## 実践: 入室メッセージを組み立てる

前のセクションで開いた作業部屋を、そのまま使います。

### Step 1: 決めた名前が表示される

左のファイル一覧で `practice` を右クリックして「新しいファイル...」を選び、`message.php` と打って Enter を押してください。

中央の編集エリアに、空のファイルが開きます。次の内容を入れてください。

```php title="practice/message.php"
<?php

$name = 'はな';

echo $name;
echo "\n";
```

`'はな'` のところは、自分の名前やニックネームに変えてもかまいません。

ターミナルで動かします。同じ場所（`/workspaces/chat-lesson`）で打ってください。

```bash
php practice/message.php
```

```text
はな
```

`echo $name;` は「`name` という名前で置いてあるものを出して」という指示です。`echo 'はな';` と書いたときと同じものが出ます。

PHP のエラーには、`on line` のうしろに数字が付きます。これは行の番号で、編集エリアの左端に上から順に並んでいます。エラーが出たときは、まずこの数字の行を見に行きます。

!!! failure "よくあるエラー"

    見た目には問題がないのに、次のように返ってくることがあります。

    ```text
    Parse error: syntax error, unexpected token "echo" in /workspaces/chat-lesson/practice/message.php on line 5
    ```

    **原因**: 指示の終わりの `;` が抜けています。`;` がないと、PHP は次の行までをひとつの指示だと思って読み進めます。形が崩れていると分かるのは、そのあとです。

    **対処法**: `;` が足りないのは、多くは数字の行の手前です。

    1. `on line` の数字の行から、1行ずつ上へ目を移す（空の行は飛ばす）
    2. 文字の書かれた行で止まり、その行の終わりに `;` を足す

    上の例では5行目のすぐ上が空の行なので、`;` が抜けているのは3行目です。

### Step 2: 文字をつなげて1文になる

名前だけでなく、「〇〇さんが入室しました」という1文にします。`message.php` を次の内容にまるごと置き換えます。

まず、次のコードの右上のボタンを押してコピーしてください。そのあと編集エリアの中を一度押してから、`Ctrl` キーと `A` キーを同時に押します（Mac では `command` キーと `A` キーです）。中身がすべて選ばれるので、あとは前の章で覚えたとおりに貼り付ければ、古い行は残りません。

```php title="practice/message.php"
<?php

$name = 'はな';

echo $name . 'さんが入室しました' . "\n";
```

同じ場所（`/workspaces/chat-lesson`）で、もう一度同じコマンドを打ちます。

```bash
php practice/message.php
```

```text
はなさんが入室しました
```

間にはさんだ `.`（半角のピリオド）が、文字をつなげる印です。`$name` に入れた名前、`'さんが入室しました'`、行を変える合図の3つが、書いた順につながって1つの文になります。

!!! failure "よくあるエラー"

    日本語を打ったあとに記号を打つと、次のように返ってくることがあります。

    ```text
    Parse error: syntax error, unexpected identifier "；" in /workspaces/chat-lesson/practice/message.php on line 3
    ```

    **原因**: 日本語入力のまま打つと、`'` や `;` などの記号と空白が全角の文字に変わります。見た目は似ていても別の文字なので、印としては働きません。

    **対処法**: 入力を半角に切り替えて、その行の記号と空白を打ち直してください。`'` ではさんだ日本語の中は全角のままで正しいので、直すのは外側だけです。同じ症状は、困ったときに戻るページにも載せてあります。

### Step 3: 計算した結果が出る

部屋にいる人数も出します。`message.php` を次の内容にまるごと置き換えてください。

```php title="practice/message.php"
<?php

$name = 'はな';
$members = 2;
$total = $members + 1;

echo $name . 'さんが入室しました' . "\n";
echo 'いま' . $total . '人がこの部屋にいます' . "\n";
```

同じ場所（`/workspaces/chat-lesson`）で、もう一度打ちます。

```bash
php practice/message.php
```

```text
はなさんが入室しました
いま3人がこの部屋にいます
```

`$members` に入れた `2` は、もとから部屋にいた人数です。`+ 1` で足しているのは、自分が入ったぶんです。計算した結果には `$total` という名前をつけてあるので、`echo` の行にはその名前を書くだけで済みます。

`$members` の `2` を別の数に変えて、もう一度動かしてみてください。`4` にすると、表示が `いま5人がこの部屋にいます` に変わります。

変数の名前を打ち間違えたときは、`Warning: Undefined variable` という行が出たあと、そこだけ空のまま表示が続きます。エラーが出たのに何かが表示されたときは、`$` のうしろのつづりを見比べてください。`$` そのものを書き忘れたときは、その場で止まります。

**確認**: `php practice/message.php` と打つと、入室した人の名前から始まる行と、人数の行の2行が表示されます。

## まとめ

- 変数は `$` を先頭に付けた名前で、`=` の右に書いたものがそこに入る
- `.` でつなぐと、変数の中身と文字を組み合わせて1つの文にできる
- 数は `'` ではさまずに書き、計算した結果にも名前をつけて置いておける

変数は、このあとチャットをつくるときにも同じ形で出てきます。入室した人の名前を変数に入れて、画面に出す文をここと同じように組み立てます。

次のセクションでは、いくつもの値をひとつのリストにまとめます。そのリストから順に1つずつ取り出すくり返しの書き方をおぼえて、会話を並べて表示します。

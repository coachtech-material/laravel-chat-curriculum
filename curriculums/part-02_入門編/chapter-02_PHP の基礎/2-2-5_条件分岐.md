# 条件分岐

送った人によって表示を変える書き方をおぼえます。

## if のしくみ

前のセクションでは、リストに入れた会話を全部同じ形で並べました。チャットの画面には、自分の送ったものと相手の送ったものが混ざって並びます。見た目が同じままだと、どれが自分の発言なのか見分けられません。

決めた条件が成り立つときだけ動かす、という書き方が `if` です。

```php
if ($name === 'そら') {
    echo 'あなたの発言です' . "\n";
}
```

`if` のうしろの `(` と `)` の中に書くのが条件です。この条件が成り立つときだけ、`{` から `}` までが動きます。成り立たなければ、その中は動きません。`(` と `)` でその書き方が使うものを囲み、`{` と `}` で動く範囲をはさむのは、`foreach` と同じです。

`===` は、左と右が同じかどうかを確かめる印です。`=`（左に右を入れる印）と見分けるために、`=` を3つ続けて書きます。比べ方は、この章では2つ使います。

| 書き方 | 意味 |
|---|---|
| `===` | 同じ |
| `<` | より小さい |

条件が成り立たなかったときにも何かしたいなら、`else` を足します。3つ以上に分けたいときは、間に `elseif` を入れます。

```php
$count = 5;

if ($count === 0) {
    echo 'メッセージはまだありません' . "\n";
} elseif ($count < 10) {
    echo 'メッセージが少しあります' . "\n";
} else {
    echo 'メッセージがたくさんあります' . "\n";
}
```

上から順に見ていって、最初に成り立ったところだけが動きます。`$count` に入っているのは `5` なので、1つめの `=== 0` は成り立たず、2つめの `< 10` で成り立ちます。出るのは `メッセージが少しあります` の1行だけです。`else` には条件を書きません。どれも成り立たなかったときの行き先です。

## 実践: 自分の発言だけ印をつける

作業部屋とターミナルは、開いたまま続けて使います。

左のファイル一覧で `practice` を右クリックして「新しいファイル...」を選び、`mark.php` と打って Enter を押してください。

中央の編集エリアに空のファイルが開きます。次の内容を入れてください。

```php title="practice/mark.php"
<?php

$me = 'そら';

$messages = [
    ['name' => 'はな', 'body' => 'こんばんは'],
    ['name' => 'そら', 'body' => 'こんばんは。いま練習しています'],
    ['name' => 'はな', 'body' => 'わたしもです'],
];

foreach ($messages as $message) {
    echo $message['name'] . ': ' . $message['body'];
    if ($message['name'] === $me) {
        echo '（自分）';
    }
    echo "\n";
}
```

`$me` に入れてあるのが、自分として扱う名前です。会話のリストは前のセクションと同じものです。`（自分）` を出す行だけ、先頭の空白が8つあります。`{` の中に入るたび、4つずつ増えます。

同じ場所（`/workspaces/chat-lesson`）で動かします。

```bash
php practice/mark.php
```

```text
はな: こんばんは
そら: こんばんは。いま練習しています（自分）
はな: わたしもです
```

`（自分）` が付いたのは、`$message['name']` が `$me` と同じだった行だけです。名前と中身を出す `echo` は3回とも動きます。`if` ではさんだ `echo` が動くのは、条件の合った回だけです。

`$me = 'そら';` の行を `$me = 'はな';` に変えて、もう一度動かしてみてください。印の付く行が、1行目と3行目に変わります。

!!! failure "よくあるエラー"

    `if` を書き足したあとに、次のように返ってくることがあります。

    ```text
    Parse error: syntax error, unexpected token "{" in /workspaces/chat-lesson/practice/mark.php on line 13
    ```

    **原因**: `if (` に対応する `)` が抜けています。

    **対処法**: `on line` のうしろの数字の行を見て、`(` と `)` が同じ数だけあるか数えてください。

次は、印を足すのではなく、出す内容そのものを分けます。`mark.php` を次の内容にまるごと置き換えてください。

```php title="practice/mark.php"
<?php

$me = 'そら';

$messages = [
    ['name' => 'はな', 'body' => 'こんばんは'],
    ['name' => 'そら', 'body' => 'こんばんは。いま練習しています'],
    ['name' => 'はな', 'body' => 'わたしもです'],
];

foreach ($messages as $message) {
    if ($message['name'] === $me) {
        echo '自分: ' . $message['body'] . "\n";
    } else {
        echo $message['name'] . 'さん: ' . $message['body'] . "\n";
    }
}
```

同じ場所（`/workspaces/chat-lesson`）で、もう一度打ちます。

```bash
php practice/mark.php
```

```text
はなさん: こんばんは
自分: こんばんは。いま練習しています
はなさん: わたしもです
```

自分の行は名前を出さずに `自分:` とし、相手の行は名前に `さん` を付けています。`if` と `else` のどちらかは必ず動くので、3件とも1行ずつ表示されます。

!!! warning "注意"

    エラーが出ないのに、3行とも `自分:` で始まることがあります。

    ```text
    自分: こんばんは
    自分: こんばんは。いま練習しています
    自分: わたしもです
    ```

    **原因**: `if` のかっこの中で、`=` が1つだけになっています。`=` 1つは「左に右を入れる」印なので、比べたことになりません。

    **対処法**: `=` を3つ続けた `===` に打ち直してください。

**確認**: `php practice/mark.php` と打つと、`$me` に入れた名前の行だけが `自分:` で始まって表示されます。

## まとめ

- `if` のうしろのかっこに条件を書くと、成り立つときだけ `{` と `}` の中が動く
- `===` は左と右が同じかどうかを確かめる印で、`=` を3つ続けて書く
- `else` で成り立たなかったときの行き先を決められ、`elseif` を足すと3つ以上に分けられる

このあとチャットの画面をつくるときも、同じ見分け方で自分の吹き出しと相手の吹き出しを分けます。

# リストとくり返し

いくつもの値をまとめて持ち、順に取り出して並べます。

## 配列とは

前のセクションでは、1つの名前に1つの値を入れました。この書き方でチャットの会話を持とうとすると、`$name1` `$name2` `$name3` と名前を増やし続けることになります。会話は何十件にもなるので、`echo` の行も同じ数だけ必要です。

いくつもの値をまとめて、1つの名前で持てるのが配列です。この教材では、以降リストと呼びます。前の章でページに並べた点の付いた箇条書きとは別のもので、こちらは PHP の中での値のまとめ方です。

```php
$names = ['はな', 'そら', 'ゆい'];

echo $names[0] . "\n";
```

`[` と `]` の中に、値を `,` で区切って並べます。取り出すときは、名前のうしろに `[0]` のように番号を書きます。番号は 0 から数えるので、1つめが `[0]`、2つめが `[1]` です。上の `echo` で出るのは `はな` です。

番号ではなく、名前をつけて取り出せる形もあります。

```php
$message = ['name' => 'はな', 'body' => 'こんばんは'];

echo $message['name'] . "\n";
```

`'name' => 'はな'` は「`name` という名前のところに `はな` を入れる」という意味です。`=>` は半角の `=` と `>` を続けて打ちます。変数に入れる `=` と役目は似ていますが、`=>` はリストの中で使い、矢印の左に名前、右にそこへ入れる値を書きます。

取り出すときは `$message['name']` のように、`[` と `]` の中へ名前を `'` ではさんで書きます。この形を名前つきリストと呼びます。上の `echo` で出るのも `はな` です。

## foreach のしくみ

リストに入れた値は、1件ずつ順に取り出して、同じことをくり返せます。その書き方が `foreach` です。

`foreach ($names as $name) {` のように、取り出すもとになるリストの名前と、取り出した1件を入れておく名前を、`as` をはさんで書きます。`(` と `)` は、どれを何と呼んでくり返すのかを囲む印です。

入れておく名前は自分で決められます。ここでは、まとめて持つほうに `s` を付けて `$names`、取り出した1件を `$name` としています。`s` が付いているほうがリスト全体です。

`{` と `}` ではさんだ中が、くり返される部分です。CSS でも `{` と `}` で「どうする」をはさんだのと同じ形です。

## 実践: 会話のリストを並べる

作業部屋とターミナルは、前のセクションから開いたまま使います。

左のファイル一覧で `practice` を右クリックして「新しいファイル...」を選び、`talk.php` と打って Enter を押してください。

中央の編集エリアに空のファイルが開きます。次の内容を入れてください。

```php title="practice/talk.php"
<?php

$names = ['はな', 'そら', 'ゆい'];

foreach ($names as $name) {
    echo $name . "\n";
}
```

`{` を打つと、閉じるほうの `}` が自動で足されます。そのまま Enter を押すと、足された `}` は下の行へ移ります。移ったあとに自分でも `}` を打つと、行が分かれているので、`'` を打ったときとは違って `}` が2つ並びます。上の見本と見比べて、`}` が余分に増えていたら消してください。

`echo` の行の先頭にある空白は、半角のスペース4つです。くり返される部分だと見て分かるように、右へずらしてあります。ずれていても同じように動くので、そろえるのに手間をかけなくてかまいません。

同じ場所（`/workspaces/chat-lesson`）で動かします。

```bash
php practice/talk.php
```

```text
はな
そら
ゆい
```

`echo` は1つしか書いていないのに、3行出ました。`$names` に並べた3つが順に `$name` へ入り、そのたびに `{` と `}` の中が動いています。

`'ゆい'` のうしろに `, 'かい'` と書き足して、もう一度動かしてみてください。出る行も1つ増えます。

!!! failure "よくあるエラー"

    行の数字が2か所に出るエラーもあります。

    ```text
    Parse error: Unclosed '{' on line 5 in /workspaces/chat-lesson/practice/talk.php on line 7
    ```

    **原因**: `{` に対応する `}` が見つからないまま、ファイルの終わりまで来ています。自動で足された `}` を消してしまったときにも起きます。

    **対処法**: 前の数字（`on line 5`）が `{` を書いた行、うしろの数字がファイルの終わりです。`{` と `}` が同じ数だけあるか数えてください。

次は、名前だけでなく発言の中身も並べます。打つ前に、組み立てを順に見ておきます。ここから続く2つのコードは左上に住所がないので、打たずに読むだけです。

1件ぶんの会話は、さきほどの名前つきリストで持てます。送った人と中身がひとまとまりになります。

```php
['name' => 'はな', 'body' => 'こんばんは']
```

これを会話の件数だけ、`[` と `]` の中に `,` で区切って並べます。名前だけのリストをつくったときと同じ形で、並べるものが文字から名前つきリストに変わっただけです。

```php
$messages = [
    ['name' => 'はな', 'body' => 'こんばんは'],
    ['name' => 'そら', 'body' => 'こんばんは。いま練習しています'],
    ['name' => 'はな', 'body' => 'わたしもです'],
];
```

外側の `[` と `]` が会話全体で、内側の `[` と `]` が1件ぶんです。内側は1行のうちに開いて閉じるので、行ごとに区切って読めます。いちばん下の `'わたしもです'` の行の終わりにある `,` は、そのままで正しいので消さずに残してください。

この `$messages` を `foreach` でくり返します。`talk.php` を次の内容にまるごと置き換えてください。

```php title="practice/talk.php"
<?php

$messages = [
    ['name' => 'はな', 'body' => 'こんばんは'],
    ['name' => 'そら', 'body' => 'こんばんは。いま練習しています'],
    ['name' => 'はな', 'body' => 'わたしもです'],
];

foreach ($messages as $message) {
    echo $message['name'] . ': ' . $message['body'] . "\n";
}
```

会話の中身は、自分の言葉に変えてもかまいません。

同じ場所（`/workspaces/chat-lesson`）で、もう一度打ちます。

```bash
php practice/talk.php
```

```text
はな: こんばんは
そら: こんばんは。いま練習しています
はな: わたしもです
```

`$message['name']` が送った人、`$message['body']` がその中身で、間に `': '` をはさんで1行にしています。

!!! failure "よくあるエラー"

    止まらずに動くのに、名前のところだけ空になることがあります。

    ```text
    Warning: Undefined array key "nama" in /workspaces/chat-lesson/practice/talk.php on line 10
    : こんばんは

    Warning: Undefined array key "nama" in /workspaces/chat-lesson/practice/talk.php on line 10
    : こんばんは。いま練習しています

    Warning: Undefined array key "nama" in /workspaces/chat-lesson/practice/talk.php on line 10
    : わたしもです
    ```

    **原因**: リストに付けた名前（`'name' =>` のところ）と、取り出すときに書いた名前（`$message['nama']` のところ）が違っています。

    **対処法**: この2か所のつづりを見比べてください。止まるエラーではないので、くり返しの回数だけ同じ組み合わせが出ます。

`,` を書き忘れたときと、`=>` を `->` と打ったときは、どちらも `Parse error` が出て止まります。前のセクションと同じように、`on line` のうしろの数字の行から上へさかのぼり、`,` と `=>` の形をたしかめてください。

**確認**: `php practice/talk.php` と打つと、`名前: 発言` の形の3行が上から順に表示されます。

## まとめ

- リストは `[` と `]` の中に値を `,` で区切って並べ、`[0]` のような番号で取り出す
- 名前つきリストは `'name' => 'はな'` の形で書き、`$message['name']` のように名前で取り出す
- `foreach` を使うと、リストに入っている数だけ `{` と `}` の中がくり返される

このあとチャットの画面をつくるときも、並べたい会話をこの形で用意します。ここで書いた形が、そのまま出てきます。

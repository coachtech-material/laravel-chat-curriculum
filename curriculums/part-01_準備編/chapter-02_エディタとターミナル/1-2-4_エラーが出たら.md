# エラーが出たら

わざと打ち間違えて、返ってきた言葉の読み方を確かめます。

## エラーの読みかた

コマンドを打ち間違えて Enter を押すと、ターミナルは英語の1行を返します。これがエラーです。書いてあるのは、どこで何ができなかったのかという事実だけです。エラーが直す場所を教えてくれる目印だというのは、昨日ふれたとおりです。

返ってきた1行は、コロンで区切られています。読むのは、そのうちの2か所だけで足ります。

左側に出ている名前は **どこで** にあたり、どの段階で止まったのかを表します。いちばん右に残っている英語は **何が** で、できなかった中身です。ここまで読めれば、直す場所はたいてい決まります。

英語は、意味が分からないままでもかまいません。この2か所の形を目で追えれば十分です。中身を日本語で知りたいときは、その部分を選んでコピーし、ブラウザの翻訳や検索にかけてください。

詰まったときにたしかめる順も昨日決めました。その2番目、エラーの言葉で調べるというのが、この読み方です。実際の形は、このあと自分で打って確かめます。

## 実践: わざと打ち間違える

前のセクションで使ったターミナルをそのまま使います。いまいる場所は `/workspaces/chat-lesson` のままです。

これから2回、わざと打ち間違えます。打ち間違えた用事は実行されずに終わるだけなので、ファイルが増えたり中身が変わったりすることはありません。

1つめは、さきほど使った `ls` を逆に打った形です。半角で次のように打って、Enter を押してください。

```bash
sl
```

1行返ってきます。

```text
bash: sl: command not found
```

行頭の `bash` は、打った言葉を受け取っているターミナル側の名前です。ここが **どこで** にあたり、ターミナル自身が答えたことを示しています。いちばん右の `command not found` が **何が** で、コマンドとして見つからなかったという意味です。あいだにはさまれた `sl` が、見つからなかった言葉そのものです。

コマンドを打つ行の `➜` も、赤っぽい色に変わります。前のセクションで見た、失敗したときの目印です。

つづりを `ls` に直して、もう一度打ってみましょう。

```bash
ls
```

さきほどと同じ2つの名前が並びます。

```text
README.md  practice
```

打ち間違えても、こうして打ち直せば先に進めます。`➜` の色も元にもどります。

!!! warning "注意"

    つづりが合っているのに `command not found` が返るときは、日本語入力のまま打っていないか見てください。混じった全角の文字は見た目で見分けにくいので、入力を半角に切り替えて打ち直します。

2つめは、フォルダの名前を1文字だけ変えた形です。`practice` の `c` を `s` にして打ちます。

```bash
cd practise
```

```text
bash: cd: practise: No such file or directory
```

**どこで** は `bash: cd:` の部分です。`cd` の名前が入っているので、コマンドは見つかっていて、その先で止まったことが分かります。**何が** は `No such file or directory` です。その名前のファイルやフォルダが無いという意味で、正しいつづりは `practice` です。

返ってきた2行を並べると、形が同じだと分かります。

```text
bash: sl: command not found
bash: cd: practise: No such file or directory
```

どちらも左側は `bash` から始まり、ここが **どこで** です。いちばん右の英語は **何が** で、あいだにはさまれた `sl` と `practise` が打ち間違えた言葉です。つづりを直せば、どちらもそのまま通ります。

この `cd` は移動できずに終わったので、いまいる場所も変わっていません。

**確認**: つづりを直した `ls` で `README.md` と `practice` の名前が出て、いまいる場所は `/workspaces/chat-lesson` のままです。返ってきた2行では、左側の **どこで** と右側の **何が** を指し分けられます。

## まとめ

- 打ち間違えると英語の1行が返り、読むのは左側の **どこで** と右側の **何が** の2か所だけ
- `command not found` は打った言葉、`No such file or directory` は指した名前が見つからないという表示
- 打ち間違いは何も残さないので、つづりを直して打ち直せばそのまま進める

次のセクションでは、困ったときに戻ってくるページを見ておきます。画面に出た言葉から自分の症状を引く使い方だけおさえておけば、通して読む必要はなく、この先で詰まるたびにそこへ戻ってこられます。

# ブラウザだけで、自分のチャットアプリをつくる

プログラミングがはじめての方のための入門教材です。文法の暗記から始めるのではなく、
早い段階から実際に動くアプリをつくりながら、HTML・CSS・PHP・Laravel の基礎を身につけます。

パソコンへのソフトのインストールはありません。ブラウザとインターネットの環境だけで、
最初のセクションから最後のセクションまで進められます。

## つくるもの

メッセージを送り合えるチャットアプリを、何もない状態から組み上げます。完成すると、次の3つができるようになります。

## 身につくこと

- **書かれたコードを読んで動かせる**: ファイルの一覧を見て、これは画面をつくるファイル、これは送られてきたものを受け取る係だと見当がつく状態になります
- **エラーが出ても手が止まらない**: ターミナルやブラウザに出る英語のメッセージから、どのファイルのどこで止まったのかをたどれるようになります
- **データを預けて取り出せる**: テーブルを設計し、データを保存し、必要なものだけを画面に並べる流れを一通り経験します

## 対象

**プログラミングをこれから始める方**に向けて書いています。前提にしているのは、ブラウザで検索ができ、メールの送受信とファイルの保存ができることだけです。タイピングはゆっくりでかまいません。

HTML を書いたことがなくても、ターミナル（黒い画面）を開いたことがなくても、最初のセクションから順に進められます。押すボタンの位置と打ち込む文字は、すべて画面つきで案内しています。

## 進め方

コードはコピーして貼り付けても最後まで完成させられますが、短いものは手で打つことをおすすめします。記号の位置やつづりが手に残ります。

1つの章が、だいたい1日ぶんです。途中で間が空いても、開発環境はそのまま残っているので、次に開けば続きから始められます。急いでいるときに飛ばせるセクションは、本文の中で案内しています。

## 必要なもの

- パソコンとインターネットの環境
- GitHub のアカウント（教材の中でつくります。無料で、クレジットカードの登録もいりません）
- Google Chrome（教材の画面と自分の画面をそろえるために使います。導入も教材の中で案内します）

パソコンへのインストール作業はありません。開発環境はブラウザの中で動きます。
